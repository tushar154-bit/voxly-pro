## 🎨 CUSTOMIZATION GUIDE

### Change Brand Colors
Edit `css/main.css`:
```css
:root {
    --primary: #6366f1;  /* Change to your color */
}
```

### Update App Name
Edit `index.html`:
```html
<title>Your App Name - Social Listening</title>
<span class="logo-text">Your Brand</span>
```

### Configure Settings
Edit `js/config.js`:
```javascript
const VoxlyConfig = {
    app: {
        name: 'Your App',
        version: '1.0.0'
    },
    // ... customize all settings
};
```

### Add Your Data
Create `data/brands.json`:
```json
{
    "yourbrand": {
        "sentiment": 75,
        "mentions": 10000,
        "platforms": { ... }
    }
}
```
