## 🎨 CUSTOMIZATION QUICK GUIDE

### Change Colors
Edit `css/main.css`:
```css
:root {
    --primary: #YOUR_COLOR;
}
```

### Change App Name
Edit `index.html` line 8:
```html
<title>Your App Name</title>
```

### Add Your Logo
Edit `index.html` line 54:
```html
<div class="logo-icon">YOUR_LOGO</div>
```

### Enable/Disable Features
Edit `js/config.js`:
```javascript
features: {
    competitorAnalysis: true,  // Set to false to disable
    // ... other features
}
```
